# Trading Desk for Mac

Trading Desk is a desktop app that runs on your own computer: a decision-support desk for stocks, funds and crypto. It gathers free market, macro and news data, checks a portfolio against the limits you set, and writes a morning brief whose numbers are checked against that data before the brief is shown.

This repository holds the notarized Mac app as a release download. It contains no source code.

- Product page, pricing and terms: https://futureinvoked.uk/projects/trading-desk/
- Download: [Releases](https://github.com/FutureInvoked/trading-desk-mac/releases)
- Requires: a Mac with Apple silicon, macOS 14 or later

## Decision support only

Trading Desk is decision support only; it never connects to a broker and is not investment advice. It never places an order.
